# NAVIS — 어선 항적 기반 조업형태 분류 · 이상항적 탐지

어선 위치 기록(V-Pass, 1시간 단위 항적)만으로
**① 어선의 조업형태(업종)를 분류**하고 **② 사고 의심 시각을 찾아내는** 해양 안전 분석 프로젝트입니다.

**📊 결과 대시보드 → https://yoojinsong-cs.github.io/navis-dashboard/**
(학습 데이터 분석 · 테스트셋 7,768척 채점 결과 · 사건 지도, 선박 번호는 비식별 처리)

> 팀 프로젝트입니다. 대회 데이터와 선박별 결과는 공개할 수 없어 이 저장소에는 **코드와 집계 결과만** 담았습니다.

---

## 문제

| 과제 | 입력 | 출력 |
|---|---|---|
| **테스트A** 조업형태 분류 | 선박의 항적 | 연안복합 · 자망 · 통발 · 채낚기연승낚시 중 하나 + 확률 |
| **테스트B** 이상항적 탐지 | 선박의 시간별 항적 | 시간별 이상항적 점수(0~1), 가장 의심되는 사고 시각 |

- 학습: 2026년 1~6월 V-Pass 항적 약 7,300척 (업종 라벨 있음, 사고 라벨 없음)
- 테스트: 2025년 1~6월 항적 7,768척, 421만 행 (업종 라벨 없음)
- 사고 라벨이 없어서 **비지도 이상탐지**로 접근하고, 인위적 사고 항적과 실제 사고 목록(167건)으로 검증했습니다.

## 접근 방법

```
원본 항적(월별 csv, 약 7GB)
   │
   ├─▶ [분류]  시간별 이동 통계 → 선박×월 특징 → LightGBM → 선박 단위 업종 확률
   │                                                     │
   └─▶ [이상탐지] 항적 특징(속력·선회·정지·신호 단절 …)        │ 업종 불일치 지표, 테스트 선박 업종
         ├ 업종×시간대×상태별 정상 기준                     ▼
         ├ Isolation Forest (상태별)          ─┐
         ├ 시퀀스 오토인코더 (PyTorch)          ├─▶ 점수 결합 → 백분위 → 사건 규칙(단절·정지·지속) → 주의/경보
         └ 업종 불일치 (분류 모델 연결)          ─┘
```

- **분류** (`NAVIS_classifier/`): 시간별 속력·정지 비율·활동 시간대 같은 통계를 선박×월 단위로 묶어 LightGBM으로 학습합니다. 같은 선박이 학습과 검증에 함께 들어가지 않도록 **선박 단위 교차검증**으로 평가했습니다.
- **이상탐지** (`NAVIS_anomaly_final/`): 정상 기준 대비 이탈, Isolation Forest, 오토인코더 재구성 오차, 업종 불일치를 결합한 뒤 바다 위 신호 단절·장시간 정지 같은 규칙으로 사건을 만듭니다. 경보 임계값은 하루 경보 20건 이하라는 운영 조건에서 인위적 사고 탐지율이 가장 높도록 골랐습니다.
- **두 모델 연결**: 이상탐지 코드가 분류 패키지를 `cls_bridge.py`로 직접 불러 씁니다. 결과 파일을 주고받지 않아서 분류 모델이 바뀌면 이상탐지에 바로 반영됩니다.
- **대용량 처리**: 테스트셋 421만 행을 선박 16묶음으로 나눠 처리하고, 묶음마다 저장해 중간에 멈춰도 이어서 실행할 수 있습니다(16GB 노트북에서 약 40분).

## 결과

| 항목 | 값 |
|---|---|
| 조업형태 분류 (처음 보는 선박 7,229척, 선박 단위 교차검증) | 정확도(micro-F1) **0.593**, macro-F1 **0.518** |
| 이상탐지 경보 운영 기준 | 하루 경보 20건 이하 (주의 ≥ 0.9507, 경보 ≥ 0.9990) |
| 인위적 사고 탐지율 | 6시간 정지 **86%**, 바다 위 신호 단절 **79%** |
| 테스트셋 채점 | 7,768척 전체 업종 예측 + 사고 시각·점수 |

자세한 수치는 `NAVIS_classifier/results/`(분류 검증 보고서, 혼동행렬, 특징 중요도)와 대시보드의 보고서 창에 있습니다.

## 실행

```bash
pip install -r requirements.txt
export NAVIS_DATA="<데이터 폴더 경로>"   # 월별 V-Pass csv, 사고현황 xlsx, 제출샘플, 테스트셋
python run_all.py --list                  # 단계와 경로 확인
python run_all.py                         # 분류 → 이상탐지 학습 → 테스트셋 채점 → 제출 파일 → 대시보드
```

데이터는 대회 제공 자료라 포함하지 않았습니다. 경로는 모두 `NAVIS_anomaly_final/navis_paths.py`에서 정하며 코드에 절대경로가 없습니다.

## 폴더 구조

| 폴더·파일 | 내용 |
|---|---|
| `run_all.py` | 전체 실행 (단계별 실행·이어서 실행 지원, 로그 저장) |
| `make_submission.py` | 제출 파일 만들기 (제출 양식에 맞춤) |
| `NAVIS_classifier/` | 조업형태 분류 (LightGBM) — [README](NAVIS_classifier/README.md) |
| `NAVIS_anomaly_final/` | 이상탐지 (정상 기준 · Isolation Forest · 오토인코더 · 사건 규칙) — [README](NAVIS_anomaly_final/README.md) |
| `NAVIS_features/` | 항적 특징 기준값 |
| `viz/` | 대시보드 · 사건 지도 생성 (데이터를 HTML에 넣어 서버 없이 열림) — [README](viz/README.md) |
